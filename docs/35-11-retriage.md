# 01 · Admissão | Reavaliar edição

Novas Issues, edições do corpo e reabertura acionam a triagem no código confiável de `admissions`. O processamento atual permanece somente leitura do código do candidato; o próprio workflow publica comentário de triagem e atualiza os rótulos. O gatilho não faz chamadas pagas de IA nem aciona publicação.

Mudanças na branch de origem sem edição da Issue são observadas pelo orquestrador privado agendado, que registra novo snapshot quando o commit muda. Remediações anteriores nunca são consideradas automaticamente resolvidas.
